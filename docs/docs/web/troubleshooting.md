# Troubleshooting

This page lists common problems of web clients and the console messages that point to them. Many problems are easier
to find on the server's [monitoring page](./monitoring.md), which shows the connected clients and their log.

## Common problems

| Symptom                                                                | Cause                                                                                                                                      | Fix                                                                                   |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `new Colibri()` throws a `ColibriError`                                | Path such as `/log`, query or fragment in the address, another scheme, a port that conflicts with the third argument, or a second instance | Pass only scheme, host and port. Use `Colibri.getInstance()`.                         |
| Clients do not see each other                                          | Different app names or servers, or the listener was not registered and connected at send time                                              | Use the same app name and server. Register listeners first.                           |
| Nothing connects from an `https://` page                               | The browser blocks `ws://` and `http://` (mixed content)                                                                                   | Use `https://` or `wss://` with [TLS](./configuration.md#tls) or a TLS proxy          |
| `Colibri: could not connect to ...` after upgrading from Colibri 1     | The address or `port` names 9011, Colibri 1's default port. Colibri 2 servers default to 9211.                                             | Use the server's port                                                                 |
| `colibri.protocolMismatch` emits with `fatal: true`                    | The server refused this client and closed the connection                                                                                   | Use Colibri 2 on both sides ([Protocol version](./configuration.md#protocol-version)) |
| `colibri.protocolMismatch` emits with `fatal: false`                   | No version announcement within 5 s, typical of a Colibri 1 server. The connection stays up.                                                | Upgrade the server to Colibri 2                                                       |
| `@Synced()` fails to compile or does not sync                          | `experimentalDecorators` is on, or a member lacks `accessor`                                                                               | Remove `experimentalDecorators`. Declare synced members with `accessor`.              |
| Vite: `Unexpected token` at `@Synced()`, or `Uncaught SyntaxError` in the browser | Vite does not translate standard decorators                                                                       | Add the plugin from [Vite](./installation.md#vite)                                    |
| Models sync in development but not in a production build or with Unity | No `name` in `RegisterModelSync`                                                                                                           | Pass `name`                                                                           |
| Unity never receives numbers from the web                              | The web client sends every number as `float`                                                                                               | Receive with `Sync.Receive<float>` in Unity, not `Sync.Receive<int>`                  |
| Colors arrive as strings or arrays                                     | Unity sends `"#RRGGBBAA"`, the web client `[r, g, b, a]`                                                                                   | Normalize with `toHexColor()` or `toRgbaColor()`                                      |
| `Sync.send*` does nothing                                              | Called before `new Colibri()`, dropped with a console warning                                                                              | Create the `Colibri` instance first                                                   |

## More problems

| Symptom                                                                         | Cause                                                                                                         | Fix                                                                                                    |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `new Colibri()` throws `A Colibri instance already exists!` in React            | The component that creates the client runs more than once                                                     | Create the client outside your components, e.g. in `main.ts`                                           |
| Two parts of a page do not see each other's object changes                      | `RegisterModelSync` or `RegisterSyncTransforms` was called twice for the same channel, e.g. in a component    | Call it once per channel, e.g. at the top level of a module, and share what it returns                |
| Changes to an array or object property are not synced                           | The array was changed in place, e.g. `position[0] = 1` or `items.push(item)`                                   | Assign a new array or object                                                                           |
| A registered object shows other values than you set                             | The server already had an object with this id, and its values win                                             | Use a new, unique id, or expect the saved values ([details](./syncmodel.md#registering-instances))     |
| A message sent by the web is not received by the same page                      | A client does not receive its own messages                                                                    | Call your handler directly after sending, as in the [example](./messages.md#example-starting-a-game-round) |
| `GetRestApi` returns `null` although a value was saved                          | Different app name or key, or the value is `null`                                                             | Check the app name and the key ([Keys](./data-store.md#keys))                                          |
| `GetRestApi`, `PutRestApi` or `DeleteRestApi` returns `undefined`               | Called before `new Colibri()`                                                                                 | Create the `Colibri` instance first                                                                    |
| `GetRestApi` throws a `TypeError`                                               | The server cannot be reached, or the page on `https://` connects with `http://`                               | Check the server address and [TLS](./configuration.md#tls)                                             |
| The browser rejects the server's certificate                                    | The server uses a self-signed certificate                                                                     | Open `https://<server-address>:9211` once and accept it ([TLS](./configuration.md#tls))                |
| A background tab reconnects only after a minute or more                         | Browsers slow down timers in hidden tabs                                                                      | Show the tab again. It reconnects within seconds.                                                      |
| The server log warns about `CLIENT_MESSAGE_RATE_LIMIT` and names your client    | Your client sends too many messages or object changes, usually in every frame                                 | Send less often, e.g. only when a value changes ([Limitations](./messages.md#limitations))             |

## Console messages

| Message                                                                                    | Meaning                                                                                                    | Fix                                                                                       |
| ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `Colibri not initialized yet! (Instance is null)`                                          | `Colibri.getInstance()`, `Sync.send*` or a data store function was called before `new Colibri()`           | Create the `Colibri` instance first                                                       |
| `Colibri: could not connect to <address> (<reason>). Retrying until it answers ...`        | The server does not answer. Colibri keeps trying.                                                          | Check the server address and port, and that the server is running                         |
| `Colibri: the app name 'colibri' is reserved for the server's admin UI ...`                | `colibri` is the app name of the monitoring page                                                           | Give your app a name of its own ([App name](./configuration.md#app-name))                 |
| `Colibri: The server did not identify itself within 5s ...`                                | The server is probably a Colibri 1 server. The connection still works.                                     | Upgrade the server ([Protocol version](./configuration.md#protocol-version))              |
| `Colibri: Server refused the connection ... Not reconnecting.`                             | The server speaks another protocol version                                                                 | Install matching Colibri versions on the server and the client                            |
| `Colibri: RegisterModelSync is syncing on channel '...', ... which looks minified.`        | `RegisterModelSync` has no `name`, and the class name was shortened by a production build                  | Pass `name` ([Registering the class](./syncmodel.md#registering-the-class))               |
| `Unknown property <property> in <class>`                                                   | Another client syncs a property that your class does not declare                                           | Add the property, or fix its name ([Syncing with Unity](./syncmodel.md#syncing-with-unitys-syncbehaviour)) |
| `Colibri: registerModel was given a second model with the id '...' ...`                    | Two different objects were registered with the same id. The second replaces the first.                     | Use unique ids, or register each object once                                              |
| `Colibri: '...' is not a colour - expected "#RRGGBBAA" or [r,g,b,a]. Using black.`         | `toHexColor` or `toRgbaColor` got a value that is not a color                                              | Check what is sent on the channel                                                         |
| `RemoteLogger: the console is already forwarded by an earlier new RemoteLogger() ...`      | `new RemoteLogger()` was called more than once                                                             | Create one `RemoteLogger` at startup ([Monitoring](./monitoring.md))                      |
| `RemoteLogger: <n> more line(s) logged before new Colibri() were not kept ...`             | More than 100 lines were logged before `new Colibri()`                                                     | Create the `Colibri` instance earlier                                                     |
| `@Synced() must decorate an accessor member` (error)                                       | `@Synced()` is on a property without `accessor`                                                            | Declare the property with `accessor`                                                      |

The messages of a `ColibriError` thrown by `new Colibri()` say what is wrong with the address or port. See
[Server address and port](./configuration.md#server-address-and-port).
